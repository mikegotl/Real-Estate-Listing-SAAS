Creative Listing Studio flow map

Every path a person can take on a property, from the Overview tab through Media to a finished campaign and its video chat. Each branch has an ID you can use as a test case name. Diagrams show the decisions; the table under each one lists the cases with starting state, steps and expected result.

How to read the IDs

  • MT-31Area prefix and case number. Numbers jump by area sub-topic (MT-2x are stops), so new cases can slot in.
  • P1 P2 P3P1 = core path or data-loss risk, run every release. P2 = important branch. P3 = edge case or copy check.
  • NeedsPaid services or settings the case depends on (OpenAI, Higgsfield, Drone AI, Photo edit AI, ElevenLabs, Lip-sync, MediaAnalysis, Google Places, Stripe). "Local run" works without them.
  • S-xxMatching scenario in the campaign test matrix spreadsheet (reviews/2026-10-26-campaign-test-matrix, updated 29 Oct). "Pairwise", "Language matrix" and "Deliverable combos" point to its other sheets.
